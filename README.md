# Turnx

Turnx is a fully responsive, modern Digital Marketing Agency website built with pure HTML, CSS, and JavaScript.

## Features
- Responsive layout (mobile, tablet, desktop)
- Glassmorphism UI with premium purple theme
- Animated gradient background and subtle bubble effects
- Sticky navbar with mobile menu and overlay
- Scroll reveal animations and accordion FAQ
- Custom cursor (desktop)
- Floating WhatsApp and scroll-to-top actions

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
